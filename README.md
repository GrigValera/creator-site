# CREATOR

Сайт услуг по веб-разработке, обновлению сайтов и автоматизации. Название и цены используются как стартовые ориентиры.

## Запуск

Нужен Node.js 22.12 или новее.

```sh
npm ci
npm run dev
npm run check
npm run build
npm run preview
```

Продакшен-сборка находится в `dist/`. Сборка предварительно генерирует HTML, а React подключает интерактивность после загрузки. Стили компонентов находятся в CSS Modules, правила конфигуратора и расценки — в `estimate.ts`.

Форма позволяет скачать локальный бриф. Для приёма заявок требуется согласовать и подключить канал доставки. Карточки работ ведут на исходники и опубликованные демо. Для хостинга сайта предусмотрена статическая сборка.
