# CREATOR

Сайт услуг по веб-разработке, обновлению сайтов и автоматизации. Название и цены используются как стартовые ориентиры.

## Запуск

Нужен Node.js 22.12 или новее.

```sh
npm ci
npm run dev
npm run check
npm run build
npm run preview
```

Продакшен-сборка находится в `dist/`. Сборка предварительно генерирует HTML, а React подключает интерактивность после загрузки. Стили компонентов находятся в CSS Modules, правила конфигуратора и расценки — в `estimate.ts`.

В `dev` и `preview` форма работает через `/api/inquiries`. Без настройки доставки запрос проходит проверку и возвращает явно обозначенное тестовое подтверждение. Бриф можно скачать отдельно.

Для рабочей доставки разверните `api/inquiries.js` на хостинге с поддержкой Node.js и задайте на сервере `CREATOR_INQUIRY_WEBHOOK` — адрес HTTPS-обработчика, который принимает JSON с полями `contact`, `task` и `estimate`. Для статической публикации адрес отдельного обработчика задаётся на этапе сборки через `VITE_INQUIRY_ENDPOINT`. Для отдельного домена обработчик должен разрешать запросы с домена сайта. Учётные данные задаются на сервере.

## Стенд Vercel

Импортируйте репозиторий в Vercel и откройте Preview нужной ветки. `vercel.json` собирает сайт в `dist`. Серверная функция доступна на том же домене по `/api/inquiries`. Используйте Node.js 22.12 или новее.

Добавьте `CREATOR_INQUIRY_WEBHOOK` в серверные переменные среды Preview и повторно разверните ветку. Адрес приёмника должен отвечать по HTTPS без перенаправления. CREATOR воспринимает ответ `2xx` как подтверждение приёма, поэтому используйте этот статус после доставки в оба канала или надёжного сохранения заявки для дальнейшей доставки. Проверьте фактическое получение в Telegram и на почте отдельно.

Черновики «Смена» и «Релей» исключены из сборки сайта. Локальные рабочие копии находятся в `demo-drafts/`.
